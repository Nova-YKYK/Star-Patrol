# 🚀 Star Patrol

Star Patrol is a retro-style arcade space shooter for Windows. Defend the galaxy from waves of pixel-art aliens, dodge their fire, and chase the highest score you can!

## ✨ Features

### 👾 Classic Arcade Gameplay - Pilot your ship left and right along the bottom of the screen. - Shoot down rows of marching aliens before they reach you. - Dodge enemy fire, with 3 lives per game. - Each wave gets faster and more aggressive as the levels go up. - Aliens speed up as their numbers shrink.

### 🏆 Scoring - Higher rows of aliens are worth more points. - Your score, level and remaining lives are shown at the top of the screen. - Beat your best to set a new high score.

### 💾 Automatic High Score Saving - Your high score saves automatically the moment you beat it. - It's kept even if you quit, return to the menu or close the game mid-run. - Your best score is shown on the title screen every time you play.

### ⏸️ Pause Menu - Pause at any time during a game. - Resume where you left off. - Return to the main menu. - Quit the game.

### 🎨 Retro Style - Crisp, pixel-art graphics scaled up from a 160×200 grid. - Animated aliens and a scrolling starfield. - Explosion particle effects. - Classic beep sound effects.

## 🕹️ Controls

| Key | Action | | --- | --- | | ← / → or A / D | Move | | Space | Fire / Start game | | Backspace | Pause / Resume | | ↑ / ↓ or W / S | Navigate pause menu | | Enter | Select menu option |

On the Game Over screen, press **Space** to play again or **Backspace** to return to the main menu.

## 📥 Installation

1. Open the **Releases** page. 2. Download the latest Windows release. 3. Extract the downloaded ZIP file. 4. Run `StarPatrol.exe`.

Star Patrol needs the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) installed, unless the release says it is self-contained.

If Windows displays a security warning, make sure you downloaded the release from this official repository before deciding whether to run it.

## 🔒 Privacy

Star Patrol only stores your high score, locally on your computer at:

``` %AppData%\StarPatrol\highscore.txt ```

Nothing is sent online. Delete this file if you want to reset your high score.
